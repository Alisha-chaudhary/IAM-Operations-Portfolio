## Evidence type definitions

- **Actual lab evidence:** Generated by executing against the local IdentityGuard API and database. Sanitised API responses and reports.
- **Simulated stakeholder evidence:** Created for the fictional training scenario to represent manager endorsements or IAM Administrator approvals not performed through the API. Not real organisational activity.
- **Policy analysis:** Analysis of governance documents (RBAC Matrix, Entitlement Catalogue, Approval Matrix, SoD Policy).
- **Untested control:** A control identified but not executed (none in this scenario; all controls tested).
